# Synthetic smoke example

All names, questions and passages in this directory are fictional test fixtures authored for this release. They are not sampled from a benchmark. Train, calibration and test question IDs are disjoint. The test includes an empty context, repeated evidence and rejected candidates.

Use the commands in the main README or reproducibility guide. `--smoke-example` explicitly uses regex features; it does not reproduce the paper NLP pipeline or scores. Never report these outputs as benchmark results.
