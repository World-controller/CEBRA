# Contributing to CEBRA

Open an issue to discuss a change, then submit a focused pull request with tests and reproduction steps. Preserve existing licenses and explain the provenance of imported code or data. Do not include credentials, private experiment logs or copyrighted datasets without redistribution permission.

Use Python 3.11 and the lightweight environment described in the README. Install `requirements-dev.txt`, then run `python -m pytest tests -q` before proposing changes. Keep algorithm/experimental changes separate from documentation and compatibility refactors. No Microsoft CLA service or CLA bot is asserted for this repository.
